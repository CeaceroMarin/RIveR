# RIveR v1.0.0

**RIveR** is an R Shiny application designed to support the establishment, verification, review, and transferability assessment of reference intervals (RIs) in clinical laboratories.

RIveR integrates direct and indirect approaches within a structured analytical and decision-support workflow. The application explicitly distinguishes between the **statistical recommendation generated by the software** and the **final professional decision made by the laboratory specialist**.

---

## Quick start

### 1. Download RIveR

Clone this repository using its GitHub URL, or download the latest release as a ZIP file.

### 2. Install the required packages

Open R or RStudio and run:

```r
source("install_packages.R")
```

This script checks and installs the packages required by RIveR.

### 3. Launch RIveR

Run:

```r
source("run_app_RIveR.R")
```

RIveR will start locally and open in the default web browser.

# Scope of RIveR v1.0.0

RIveR v1.0.0 provides four principal analytical workflows:

1. **Direct reference interval establishment**
2. **Indirect reference interval establishment**
3. **Direct reference interval verification**
4. **Indirect reference interval verification**

The application also integrates:

- assessment of qualitative covariates
- assessment of quantitative covariates
- evaluation of potential RI partitioning
- continuous quantitative modeling where supported by the data
- review of extreme observations
- documentation of analytical decisions
- persistent execution and recovery of long-running calculations
- separation between statistical recommendations and final professional approval.

RIveR does not automatically implement a reference interval. Its outputs are intended to support specialist review and documented laboratory decision-making.

# Data confidentiality

RIveR does not require direct patient identifiers for its analytical workflows.

Users should not import unnecessary personally identifiable information.

Where row-level traceability is required, use:

- pseudonymized identifiers
- study identifiers
- non-identifying laboratory request codes where institutionally permitted.

Users remain responsible for ensuring that data processing complies with:

- institutional policies;
- applicable data-protection legislation;
- ethics requirements;
- local governance procedures.

# Intended use

RIveR is intended as a scientific and professional decision-support tool for reference interval studies in clinical laboratories.

RIveR is not intended to:

- make autonomous clinical decisions
- replace qualified specialist interpretation
- diagnose individual patients
- classify individual observations as pathological solely from an indirect statistical model
- automatically implement reference intervals
- replace local validation requirements
- replace applicable accreditation, ethical, institutional, quality, or regulatory requirements.

---

# Important interpretation principles

When using RIveR:

- do not equate statistical significance with a requirement for partitioning
- do not automatically remove observations because they are statistically extreme
- do not assume that a large routine dataset necessarily represents a valid reference population
- do not interpret the estimated non-pathological fraction as an individual patient diagnosis
- do not adopt a continuous model without reviewing biological and clinical plausibility
- do not interpret software-generated recommendations as automatic clinical approval
- document any professional override of the statistical recommendation.

---

# Methodological framework

RIveR incorporates methodological concepts from the international reference interval literature and relevant CLSI guidance.

Depending on the selected workflow, the methodological framework includes concepts related to:

- direct reference interval establishment
- non-parametric estimation
- robust estimation
- transformed estimation
- identification and review of extreme observations
- RI partitioning
- Lahti criteria
- Harris–Boyd criterion
- indirect RI estimation
- refineR
- reflimR
- RIbench
- VeRUS
- GAMLSS
- continuous centile modeling
- direct RI verification
- CLSI guidance for RI establishment, implementation, and verification.

The references supporting each analytical module are documented in the scientific documentation and should be reported in scientific publications using RIveR.
